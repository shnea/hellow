# 상담사 화면 UI 정의서

## 2026-10-03 추가 확정 흐름

- 상담 요청이 없는 상태에서도 고객 목록·과거 상담 조회/수정·새 기록 작성은 열려 있어야 한다. 대기열은 실시간 요청을 처리하는 문맥이며 고객 기록 조회의 필수 조건이 아니다.
- 새 연락은 작은 알림에 그치지 않고 고객명·연락 유형·내용과 수락 액션을 갖춘 큰 수신 모달로 표시한다. 나중에 확인을 선택하면 요청은 대기열에 유지한다.
- 음성 통화 종료 후 기록 저장·완료까지는 후처리 상태다. 이 상태에서 새 음성 통화를 받을 수 없으며 화면과 서버 모두 차단한다.
- 태블릿과 모바일 웹을 지원한다. 데스크톱의 여러 패널을 축소하지 않고 좁은 화면에서는 대기열·편집기·이력을 전환하며 고객/기록 목록도 별도로 열 수 있게 한다. 화면 전환은 진행 중 미디어와 작성한 초안을 유지한다.

사용자 확인 및 의사결정 결과:
- **기반 구도**: **B안(처리할 일과 상담 흐름 중심) 기반**
- **글로벌 메뉴**: **C안의 좌측 글로벌 내비게이션 바(슬림 아이콘 탭) 결합**
- **업무 처리 특성**: 한 화면에서 고객정보·이력·통화 제어·상담 기록을 모두 처리하는 고밀도 워크스페이스
- **추가 요구 반영**:
  1. 상담 이력을 탐색하면서 후속 업무(서비스 예약, 콜백 예약, 타 부서 호전환)를 즉시 연계하여 처리
  2. 통화 중 실시간으로 긴 내용을 입력할 수 있도록 중앙 상담 메모 작성 영역을 충분히 넓게 확보
  3. 구현 방식: Next.js App Router, TypeScript, 가상 데이터 기반 프로토타입 예정 (이번 단계는 정의 완료 및 Git 보관)

## 2. 구획별 상세 기능 및 컴포넌트 정의

### ① 최좌측 글로벌 내비게이션 바 (GNB, 폭 64px)
* **목적**: 시스템 전역 메뉴 탐색 및 상담사 근무 상태 표시
* **구성 요소**:
  - 서비스 브랜드 로고 아이콘 (`hellow`)
  - 메뉴 아이콘:
    - 📞 **상담 워크스페이스 (현재 활성 화면)**
    - 👥 **고객/거래처 디렉터리**
    - 🎫 **티켓 & 상담 이력 전체 조회**
    - 📊 **상담 통계 및 대시보드**
    - ⚙️ **조직 및 시스템 설정**
  - 하단: 상담사 프로필 아바타 + 근무 상태 인디케이터 (온라인 / 상담 중 / 자리비움 / 퇴근)

### ② 처리 대기열 패널 (Queue Panel, 폭 약 20%)
* **목적**: 실시간 인입 콜 및 상담사가 당일 처리해야 할 대기 업무 모니터링 및 전환
* **구성 요소**:
  - **상태 카운터 & 탭**: 전체 대기 건수, 인바운드 콜(Live), 콜백 예약, 배정 티켓
  - **실시간 인바운드 콜 항목**: 수신 발생 시 강조 애니메이션(깜빡임), 대기 시간, 발신 번호, 고객명
  - **대기 콜백 항목**: 약속 시간, 고객명, 문의 사유, 즉시 발신 버튼
  - **배정 티켓 항목**: 우선순위(긴급/보통), 접수 채널(웹/채팅), 미처리 시간
* **인터랙션**: 대기열 항목 클릭 시 중앙 워크스페이스가 해당 고객 맥락으로 즉시 전환

### ③ 중앙 활성 상담 워크스페이스 (Workspace, 폭 약 48%)
* **목적**: 현재 연결된 통화 제어 및 방해 없는 상담 내용 집중 작성
* **구성 요소**:
  - **상단 통화 컨트롤러**:
    - 통화 진행 상태 및 경과 시간 (`04:12`)
    - 발신자 전화번호 및 고객명
    - 주요 제어 버튼: 음소거, 통화 보류(Hold), 호전환, **통화 종료**
  - **고객 요약 카드**:
    - 고객명, 직급/부서, 회사명, 고객 등급(VIP), 최근 연락처, 최근 상담일
  - **확장형 실시간 상담 메모 작성기 (핵심)**:
    - 상담 대분류 / 중분류 선택 드롭다운 (예: 제품 문의, 계약/정산, 기술 지원, 장애/불만)
    - 처리 상태 라디오 (진행 중 / 완료 / 에스컬레이션)
    - 자주 쓰는 분류 태그 칩 (견적 재검토, 방문 요청, 가격 협상 등)
    - 넓은 서식 텍스트 에디터 (글머리 기호, 굵게, 빠른 문구 삽입 지원)
  - **하단 액션 바**:
    - [임시 저장], [상담 종료 및 완료], [관리자 에스컬레이션]

### ④ 우측 고객 맥락 및 후속 조치 패널 (Context & Actions, 폭 약 32%)
* **목적**: 고객의 과거 이력을 한눈에 확인하며, 통화 도중 필요한 후속 서비스(예약, 이관, 알림)를 즉시 연계
* **구성 요소**:
  - **상단: 고객 통합 상담 타임라인**:
    - 채널별 필터 (전화, 이메일, 채팅, 헬프데스크 티켓)
    - 시간 역순 정렬 타임라인 카드 (일시, 상담원, 채널, 요약 메모, 녹취/메시지 원문 토글)
    - 타임라인 내 특정 이력 클릭 시 해당 내용 인용/참조 기능
  - **하단: 연계 후속 조치 패널**:
    - **서비스/방문 예약**: 엔지니어/담당자 방문 일정 선택, 서비스 유형 지정, 캘린더 연동
    - **콜백 일정 등록**: 재통화 희망 일시 지정 및 캘린더 큐 등록
    - **호전환 / 이관**: 부서별 가용 상담사 실시간 조회 및 원클릭 호전환/티켓 이관
    - **고객 안내 발송**: 상담 요약 또는 견적/안내 링크 SMS/알림톡 템플릿 즉시 발송
