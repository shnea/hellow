# 목록·현황 화면 디자인 일치

2026-10-04 사용자 요청: 콜백·방문 예약, 상담이관, 상담 현황·기본 통계를 **My 상담 이력** 디자인에 맞춘다. 요청 구분/상태처럼 적은 필터가 한 줄을 전부 차지하지 않도록 제한한다.

## 적용 기준

- 기존 My 상담 이력의 `consultation-history.css`가 시각 기준이다. `work-list.css`에서 세 대상의 공통 제목·버튼·조회 조건·표·페이지 이동 스타일을 공유한다. 이력 화면 자체와 업무/API·권한·집계 계약은 바꾸지 않는다.
- PC 제목20px/650, 설명13px, 좌우24px·위아래20px. 900px 이하 패딩16px, 600px 이하 패딩12px·제목18px. 기본 버튼36px·반경6px, 모바일과 상세 팝업은44px다.
- 필터마다 최대240px, flex grow0으로 적은 조건이 남은 너비를 채우지 않는다. 좁은 화면은 두 열 범위에서 축소한다. 모바일 조회 조건 접기/열기와 표 내부 가로 스크롤을 제공한다.
- 목록은 기존 더블 클릭/상세 보기, 단일 클릭 무동작을 유지한다. 헤더·페이지/건수 안내·페이지 이동과 빈/로딩/오류 메시지를 이력의 위치와 색상에 맞춘다. 상세 팝업은 업무 폼에 맞는 최대880px 안에서 같은 헤더·테두리·여백을 사용한다.
- 현황·통계는 같은 제목·버튼·조회 조건·표 헤더·페이지 이동을 사용하며 차트·정확한 수치·정의·갱신 성공 시각과 기존 권한 범위를 유지한다. 숫자 표는 모바일 카드로 바꾸지 않고 가로 스크롤을 유지한다.

## Direction contract

THESIS: 서로 다른 상담 업무를 오갈 때 My 상담 이력의 동일한 목록 조작과 시각적 위계를 유지한다.
OWN-WORLD: 기존 slate 바탕 #0f172a, 표면 #1e293b, 테두리 #475569, indigo 선택 상태와 앱 글꼴을 사용한다.
STORY: 제목/설명 → 제한된 조회 조건 → 페이지/건수 또는 마지막 성공 시각 → 목록/차트 → 명시적 상세/페이지 이동.
FIRST VIEWPORT: 이력과 같은 패딩과 제목, 오른쪽 동작 버튼, 최대240px의 필터와 구분선, 표 머리와 정확한 값. 모바일은 접힌 필터와 같은 목록 구성이다.
FORM: 사용자가 기존 My 상담 이력으로 방향을 지정한 좁은 확장이다. 새 콘셉트 추첨·comp 승인·디자인 시스템 교체는 적용하지 않는다.
FINISH: 실제 화면 크기별 비교, 동작 검사, 독립 finish review와 documenter 확인, 개발 웹 반영·인계 기록으로 끝낸다. 기존 DESIGN.md 부재와 이전 comp 설정을 임의 정비하지 않는다.
