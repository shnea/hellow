# 데이터·파일·상태 관리

필요시 확인: 데이터·파일·저장·삭제·동시 수정·이관을 다룰 때.

적용 범위: 조건부. 데이터를 저장·교환하거나 상태·파일을 다룰 때 적용한다.

## 공통 설정·분류·템플릿의 상속과 기록 보존

- 공통 기본값 → 조직별 오버라이드로 적용한다. 조직에서 지정하지 않은 항목은 공통값을 따르고 지정한 항목은 이후 공통 변경에도 유지한다. 상속 상태·실효값·설정 출처를 구분하고 기본값 복원을 지원한다. 공통 변경의 영향 조직을 확인할 수 있어야 한다.
- 개인 템플릿은 별도 개인 소유 항목이다. 조직 공유 템플릿을 수정하거나 권한 설정을 우회하는 오버라이드로 취급하지 않는다.
- 상담 분류는 안정적인 ID와 부모 관계로 1~3단계를 검증한다. 비활성 분류는 새 상담에서 선택하지 못하게 하되 기존 기록은 보존한다. 기존 상담의 분류명·경로 의미가 이름 변경·삭제로 바뀌지 않도록 저장 시점 표시값 또는 버전을 보존한다.
- 템플릿 삽입 결과는 상담 문서의 독립 내용으로 저장한다. 원본 템플릿 변경·삭제가 이미 작성된 상담 내용을 바꾸지 않는다.
- 공통/조직 설정의 동시 수정 충돌과 변경 이력을 처리한다. 설정 상속은 제품 설정에 적용하며 Permission이나 비밀값을 자동 상속해 권한을 확대하지 않는다.

### 현재 분류·템플릿 저장 계약

- 분류/결과 목록은 공통 목록을 상속하거나 조직 전체 목록으로 오버라이드한다. 분류는 1~3단계 중 어느 단계에서든 선택할 수 있다. 순환·누락 부모·동일 부모의 중복 이름·비활성 부모 아래 활성 항목을 거부한다. 기존 ID를 제거할 수 없고 비활성화한다. 결과는 신규 완료 시 필수다.
- 상담은 분류 ID·경로 배열의 JSON·결과 ID·결과명을 함께 저장한다. 기존 ID를 그대로 사용하는 수정은 당시 표시값을 유지하며 비활성 항목도 유지할 수 있다. 새 선택에는 현재 활성 목록을 적용한다. ID가 없는 과거 기록은 기존 표시값을 그대로 유지할 수 있으며 이름으로 ID를 추정하지 않는다. 이미 완료된 과거 기록의 편집에 새 결과 선택을 강제하지 않는다.
- 공통/조직 목록은 저장 버전과 공통 버전을 함께 검사한다. 가상 기본 목록의 버전은 0, 첫 실제 저장 이후는 1 이상이다. 공통 변경 후 오래된 값을 복사하거나 복원하는 요청도 충돌로 거부한다.
- 공통 템플릿은 항목별로 조직 오버라이드하며 조직이 지정한 이름·본문·활성 상태를 유지한다. 복원 시 공통을 다시 상속한다. 새 조직 전용 항목과 개인 항목은 별개다. 비활성 항목은 삽입 목록에서 숨기며 실제 상담 문서의 이전 복사 내용은 유지한다. 템플릿 본문은 일반 텍스트/Markdown이고 첨부 권한을 대신하지 않는다.

## 고객 등록 전 이력의 현재 연결 계약

- 활성 상담에서 신규 등록·기존 고객 연결 시 그 접수의 저장된 상담 초안·타임라인·후속 요청을 같은 고객에 원자적으로 연결한다. 본문·작성자·시각·분류·결과와 파일의 접수 문맥은 유지하며, 연결 응답의 상담 버전을 사용해 미저장 초안을 덮어쓰지 않고 후속 저장을 계속한다.
- 등록된 고객의 ‘이전 이력 연결’에서 연락처로 후보를 조회한다. 숫자만 비교해 공백·하이픈 차이를 무시하지만 국가번호나 고객 동일성을 추정하지 않는다. 완료된 접수 중 고객이 연결되지 않고 권한이 허용된 상담/타임라인이 있는 항목만 후보로 제공한다. 이름·당시 연락처·담당·분류·시각을 확인한 직원이 최대 20건을 선택하고 같은 고객임을 확인한 후 연결한다. 연락처 일치만으로 자동 병합하지 않는다.
- 선택 시점의 접수/상담 버전을 검사하고 접수 코드 순서로 잠근다. 배치 중 하나라도 충돌·권한 위반이면 전부 롤백한다. 이미 연결된 고객은 이 기능으로 다른 고객에 재배정할 수 없다. 원래 접수 이름·연락처를 보존하며 연결자·시각·접수·고객 관계를 별도로 저장한다.
- 연결 기록에서 잘못된 연결을 취소할 수 있다. 현재 접수/상담 버전과 관계를 다시 확인하고 상담·타임라인·후속 요청의 고객 관계만 비운다. 원문과 변경 이력은 삭제하지 않으며 취소 시각·감사를 보존한다. 기존에 고객이 연결된 기록이나 연락처/접수 근거가 없는 과거 기록은 이름만으로 소급 연결하지 않는다.
