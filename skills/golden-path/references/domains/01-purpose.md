# 목적·사용자·성공 기준

필요시 확인: 최초 정의, 목적·사용자·성공 조건 변경.

적용 범위: 공통 정의 항목. 프로젝트가 해결할 문제를 이해할 때 가장 먼저 다룬다.

| 항목 | 함께 정할 내용 | 상태·현재 기준·근거 |
| --- | --- | --- |
| 해결할 문제 | 지금의 불편, 만들려는 이유, 해결 후 달라지는 점 | 확정: 고객 접점부터 상담 배정·처리·후속 업무·통계를 하나의 흐름으로 관리하는 범용 B2B CRM SaaS. |
| 주요 사용자 | 누가 사용하는지, 숙련도, 개인·팀·외부 고객 여부 | 확정: Platform Super Admin, Organization Admin, 상담 관리자, 상담사. 외부 고객은 별도의 고객용 상담 진입점을 이용한다. |
| 사용 상황 | 어디서·얼마나 자주·어떤 기기나 도구로 사용하는지 | 확정: 회사·팀 단위 상담 운영. 직원 CRM과 외부 고객 웹 상담을 구분한다. 구체적인 동시 사용자 규모는 미정. |
| 핵심 가치와 성공 기준 | 사용자가 어떤 일을 마치면 유용한지, 결과를 어떻게 확인할지 | 확정: 요청 → Queue → 배정 → 고객 식별·과거 이력 → 상담·기록 → 콜백/예약/이관 → 통계 흐름. Organization 격리와 실패 복구를 검증할 수 있어야 한다. |
