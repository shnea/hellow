# 기술·의존성·실행 환경

필요시 확인: 언어·프레임워크·의존성·실행 환경을 선택하거나 변경할 때.

적용 범위: 공통 정의 항목. 목적·제약이 정리된 뒤 구현에 필요한 것부터 선택한다.

| 항목 | 함께 정할 내용 | 상태·현재 기준·근거 |
| --- | --- | --- |
| 제품 형태 | 웹·API·CLI·라이브러리·모바일·데스크톱 등 필요한 형태 | 확정: 범용 B2B 상담 CRM 웹 SaaS와 고객 웹 상담 진입점. |
| 언어·런타임·프레임워크 | 선택 이유, 유지보수 가능한 버전, 기존 환경 호환성 | 현재 코드: Java 21, Gradle 8.12.1, Spring Boot 3.4.4, Spring Security, JPA, PostgreSQL 17.11; Next.js 16.3.8 App Router, React 19.2.8, TypeScript 5. QueryDSL은 초기 기준의 선택 후보이며 현재 의존성에는 없다. |
| 개발·실행 환경 | 지원 OS, 로컬·컨테이너·관리형 환경, 필요한 도구 | 확정: 개발·운영 Docker Compose. 운영 linux/amd64, DSM 7.2, Compose v2.20.1-6047-g6817716. 상세는 환경 기준 문서. |
| 의존성 관리 | 패키지 관리자·버전 고정·라이선스·도입과 업데이트 기준 | 현재: SHNEA Editor와 LiveKit을 사용한다. LiveKit 서버 이미지는 개발 Compose에서 `latest`이며 운영 버전 고정·호환 검증은 남았다. |
| 실행·빌드 방법 | 다른 PC에서 재현할 준비 사항과 실제 명령 | 현재: Gradle 서버와 npm 화면 빌드·테스트를 실행했다. 명령·검증 범위·미실행 운영 수락은 [검증 영역](11-validation.md)을 따른다. |
