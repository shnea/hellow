# 기술·의존성·실행 환경

필요시 확인: 언어·프레임워크·의존성·실행 환경을 선택하거나 변경할 때.

적용 범위: 공통 정의 항목. 목적·제약이 정리된 뒤 구현에 필요한 것부터 선택한다.

| 항목 | 함께 정할 내용 | 상태·현재 기준·근거 |
| --- | --- | --- |
| 제품 형태 | 웹·API·CLI·라이브러리·모바일·데스크톱 등 필요한 형태 | 확정: 범용 B2B 상담 CRM 웹 SaaS와 고객 웹 상담 진입점. |
| 언어·런타임·프레임워크 | 선택 이유, 유지보수 가능한 버전, 기존 환경 호환성 | 확정: Java / Spring Boot / Spring Security / JPA / QueryDSL / PostgreSQL. Next.js App Router / TypeScript. 구체 버전은 미정. |
| 개발·실행 환경 | 지원 OS, 로컬·컨테이너·관리형 환경, 필요한 도구 | 확정: 개발·운영 Docker Compose. 운영 linux/amd64, DSM 7.2, Compose v2.20.1-6047-g6817716. 상세는 환경 기준 문서. |
| 의존성 관리 | 패키지 관리자·버전 고정·라이선스·도입과 업데이트 기준 | 확정: SHNEA Component·Editor 재사용, Media 인프라 재사용. LiveKit 우선 검토; 제품·버전·라이선스·호환성 검증 후 결정. 패키지·빌드 도구와 잠금 정책은 미정. |
| 실행·빌드 방법 | 다른 PC에서 재현할 준비 사항과 실제 명령 | 미구현: 앱 빌드·실행 명령 없음. 실제 선택과 명령은 구성 후 검증 영역에 기록한다. |
