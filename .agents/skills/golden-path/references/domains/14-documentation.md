# 문서·인수인계·기준 유지

필요시 확인: 문서·인수인계·프로젝트 기준 관리 방식을 변경할 때.

적용 범위: 공통 정의 항목. 다음 사람·에이전트가 이어갈 수 있을 만큼 유지한다.

| 항목 | 함께 정할 내용 | 상태·현재 기준·근거 |
| --- | --- | --- |
| 첫 실행 안내 | 준비 사항, 설정, 실행·검사 명령, 새 환경에서의 확인 | 현재: 구현 전 문서 단계. 실행 명령은 생성·검증 후 검증 영역과 시작 문서에 기록한다. 다음 작업은 인계 문서를 읽는다. |
| 상세 문서 범위 | 설계·사용법·운영 문서 중 필요한 것과 기준 문서의 위치 | 확정: 요구사항 원문은 제품 원칙의 근거, 골든패스는 현재 기준, docs/infrastructure.md는 환경 상세, docs/development.md는 협업 상세. 수치·API·운영 절차는 필요한 시점 하위 명세 작성. |
| 변경과 인계 | 중요한 결정의 이유, 진행 상태·남은 일·알려진 제한 | 확정: 중요한 결정은 decisions.md, 실제 완료·검증·남은 일은 docs/handoff.md. 미정·후보·후속 범위를 확정 구현으로 바꾸지 않는다. |
| 템플릿 유지 | 적용 버전, 원본 업데이트 검토 방식, 프로젝트별 예외 보존 | 확정: Bonfire v1의 항목·14개 영역·연결 양식·내보내기/가져오기 유지. 원본 업데이트와 프로젝트 기준 변경을 구분하고 출처·버전·해시를 보존한다. |
