# 화면·접근성·사용성

필요시 확인: 화면·사용자 문구·접근성·기기 대응을 바꿀 때.

적용 범위: 조건부. 화면이나 사람이 직접 사용하는 인터페이스가 있을 때 적용한다. CLI라면 명령·출력·도움말 기준으로 바꾼다.

| 항목 | 함께 정할 내용 | 상태·현재 기준·근거 |
| --- | --- | --- |
| 정보와 행동의 순서 | 사용자가 먼저 볼 내용, 주요 동작, 탐색·진입 경로 | 확정: 고객 식별·과거 상담·현재 상담·기록·이관/후속 연락을 한 흐름에서 지원. 직원 CRM과 고객 접수 화면 분리. 공통 Shell에 AI 패널 확장 가능. |
| 시각적 기준 | 기존 디자인·참고 화면, 색·글꼴·간격·공통 요소 | 확정: SHNEA 공통 Component·Editor 재사용. 고객 진입점 최소 로고·색상·문구 설정. Impeccable은 UI 설계·검수에 사용. 구체적인 디자인 토큰·글꼴·테마는 미정. |
| 기기와 입력 방식 | 모바일·PC·키보드·터치, 확대·좁은 화면 대응 | 확정: 고객 웹 상담은 HTTPS·마이크 권한 확인. iframe/WebView/인앱 브라우저 지원은 별도 검증하며 실패 시 외부 브라우저·허용 대체 경로 안내. 지원 기기·브라우저 행렬 미정. |
| 접근성과 표현 | 읽기 쉬운 문구, 레이블·초점·색 외 상태 표시, 지원 언어 | 확정: Tenant 대신 조직/회사, ACD 대신 상담 배정 방식 등 사용자 언어 사용. 커스터마이징으로 동의·고지·통화 상태·취소/종료·접근성을 제거하지 않는다. |
| 상태와 피드백 | 로딩·빈 화면·오류·성공·재시도·취소·미저장 상태 | 확정: 로딩·오류·미등록 고객·초안/확정 기록 구분. 운영시간 외·상담사 부재·대기 초과·취소·연결 실패 구분. 수신 수락/거절·종료·음소거·보류/재개·이관 상태 표시. |
