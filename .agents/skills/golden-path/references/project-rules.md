# 영역별 기준

**필요한 영역만 확인한다.** 먼저 [현재 핵심 기준](core.md)을 읽고, 아래에서 현재 작업과 변경 영향에 관련된 파일을 고른다. 14개 영역의 본문을 일괄 로딩하지 않는다.
