# Impeccable 출처

- 공식 사이트: https://impeccable.style
- 원본: https://github.com/pbakaus/impeccable/tree/main/.agents/skills/impeccable
- 설치 경로: `.agents/skills/impeccable/`
- SKILL.md 선언 버전: 4.5.0; scripts/VERSION 엔진 버전: 0.1.11.
- main에서 공식 skill-installer로 내려받은 원본이다. 특정 커밋으로 고정했다고 주장하지 않으며 정확한 파일 식별은 [SHA256SUMS.json](SHA256SUMS.json)을 따른다.
- 원본 라이선스와 고지: [LICENSE](LICENSE), [NOTICE.md](NOTICE.md). 두 파일은 공식 저장소 main에서 함께 보관했다.
- 스킬 본문·참조·실행 스크립트는 수정하지 않았다. 프로젝트 적용 범위와 예외는 golden-path의 skills.md에서 관리한다.
- Windows 실행: `scripts/impeccable.cmd`. 공식 launcher가 버전별 엔진을 사용자 캐시에 준비하며 최초 다운로드 시 네트워크 접근이 필요하다.
