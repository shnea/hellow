# 조직 협업 탭 — Operate

기존 상담 쉘/목록/대화 패턴의 확장. 사용자 지정 탭 두 개와 기존 목록 디자인 계약/F03/F06 구조를 따른다. 추가 시각 정체성·concept-seed·comp는 해당 없음. 기존 DESIGN/comp drift는 복구하지 않는다.

## Direction contract

THESIS: 상담 맥락을 유지한 채 동료와 대화하고 정확한 게시 지식을 찾는다. UI는 기존 권한/목록/대화 계약의 확장이다.
OWN-WORLD: slate 바탕과 경계, indigo 선택·주요 동작, 동일 sans와 lucide 아이콘. 새로운 색상·폰트·표현 체계를 만들지 않는다.
STORY: 탭 선택→지식 검색/원문/편집·게시 또는 내부 방 선택/참여자/대화→기존 상담으로 돌아가도 통화·초안이 남는다. 실제 데이터·권한 및 실패 복구를 표시한다.
FIRST VIEWPORT: 기존 좌측 메뉴에 두 메뉴. 지식은 제목/설명/주요 동작, 최대240px 조건과 목록을 유지하고 선택 시 기존 상세·편집을 공통 상세보기 팝업에 표시한다. 닫기/Escape 뒤 목록 조건과 초안을 유지한다. 내부 채팅은 방 목록·미읽음과 선택한 대화의 참여자/기록/입력; 이미지 썸네일 아래 중복 원본 버튼은 숨기고 클릭으로 원본을 연다. 작은 화면은 방 선택과 대화를 왕복한다. 각 동작은44px 이상, 대화 최대75ch/85%.
FORM: 기존 구조 확장으로 시드 해당 없음. 작성·조회·게시 권한을 상태/동작으로 드러내고 발신자 기준 좌우 배치를 재사용한다. 안정적 지식 링크와 미읽음이 업무 위치를 기억시킨다.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
